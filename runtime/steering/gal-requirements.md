# GAL Requirements — v0.4.7

Preserve these controls:
- explicit evidence -> SUPPORTED
- logically unavoidable -> DERIVED
- plausible but not necessary -> INFERRED
- recommendation/design choice -> PROPOSED
- missing information -> UNKNOWN
- disagreement -> CONFLICT

Additional rules:
- absence is not negative evidence
- actor capability requires evidence
- outcome does not imply mechanism
- generated `.gal/context/*` views are read-only to AI
