# Project context

## Identity
- Marketing identity: **GAL Labs**, home of the **GAL Method — Guide · Align · Lead**.
- Repository: `alavear1110/GAL-Labs`; default branch: `main`.
- “GAL” is the method/runtime shorthand. Repository slugs, runtime versions, and canonical enum names retain their established technical meaning.

## Purpose and users
GAL helps analysts, product owners, developers, and technical teams gather and review requirements with explicit evidence, unresolved questions, human decision ownership, and truthful readiness. GAL Core defines the method independently of the AI provider or host.

## Architecture and entry points
- [GAL Core](../../runtime/steering/gal-core.md) owns methodology and semantics.
- The [Host Adapter Contract](../../runtime/contracts/HOST-ADAPTER-CONTRACT.md) governs host integrations; reviewed adapter sources live under [runtime/adapters](../../runtime/adapters/).
- [PowerShell runtime](../../runtime/gal.ps1), schemas, and templates initialize, validate, synchronize, and calculate readiness. The documented baseline is v0.5.1 with PowerShell 7+.
- In initialized GAL projects, `.gal/state/project-state.json` is canonical writable GAL state. `.gal/context/*` is generated by the runtime and read-only to AI. Neither path is committed in this development repository snapshot.
- These repository-context documents orient contributors; they do not replace canonical GAL state, redefine Core, or certify host compatibility. Provider-specific context discovery files are separate from reviewed GAL runtime adapters.

## Working agreements
Read the existing [root loader](../../AGENTS.md), GAL Core, and the relevant canonical host adapter before GAL-managed requirements work. Preserve exact GAL vocabulary, evidence classifications, question persistence, and execution truth. Only claim validation PASS after the deterministic validator successfully runs.

Do not directly edit generated `.gal/context/*` views, weaken PowerShell trust controls, or include sensitive project evidence in public issues. Keep regression fixtures and answer keys out of runtime packages and blind conformance projects. Public packages use an allowlist; development context and test assets are not customer deliverables. The repository is source-visible under an all-rights-reserved license.
