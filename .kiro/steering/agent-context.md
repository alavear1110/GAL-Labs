# Repository context entry point

Use root `AGENTS.md` as the shared entry point. Before planning or editing, read
`docs/agent-context/README.md`, `docs/agent-context/PROJECT.md`,
`docs/agent-context/STATUS.md`, and `docs/agent-context/DECISIONS.md` from the
repository root, then the existing project-specific and scoped instructions.
Reload them after every pull, checkout, branch switch, merge, rebase, other HEAD
change, or change to context files. Check current code against the status
snapshot and update the handoff after substantive work. All paths are relative
to the repository root. Keep project facts in the shared context files rather
than adding a separate memory here. Repository discovery is independent of
runtime/governance host compatibility; preserve documented runtime loaders.
